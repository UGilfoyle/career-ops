# CareerOps ATS Auto-Fill Chrome Extension

**1-Click Form Filling for Greenhouse, Lever, Workday, Ashby, BambooHR, and LinkedIn.**
Inspired by LoopCV's extension model, but local-first and privacy-preserving.

---

## 🚀 How to Install in 30 Seconds

1. Open your Chromium browser (Chrome, Brave, Edge, Arc).
2. Navigate to `chrome://extensions`.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** and select this directory:
   ```
   path/to/career-ops/extensions/careerops-autofill
   ```
5. Navigate to any job application page (e.g. `jobs.lever.co/...` or `boards.greenhouse.io/...`).
6. Click the floating **"⚡ Auto-Fill with CareerOps"** button in the bottom right corner or the extension popup. All matching fields will be instantly populated and validated!
