# Senior Full-Stack Engineer

## About the role
We are looking for a Senior Full-Stack Engineer to design, implement, and scale web applications.

## Responsibilities
- Build and own React and TypeScript front-end features
- Develop Node.js backend services and RESTful APIs
- Ship production systems on AWS with Docker
- Improve CI/CD pipelines and testing (Jest)
- Collaborate with product and engineering partners

## Requirements
- Strong experience with React, TypeScript, JavaScript, Node.js
- Experience with PostgreSQL or similar relational databases
- Familiarity with AWS, Docker, and microservices
- Hands-on with LLM integrations or AI-assisted development is a plus
- 5+ years of software engineering experience
