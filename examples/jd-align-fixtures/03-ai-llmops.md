- Design and operate RAG pipelines with vector search
- Integrate OpenAI / Claude / GPT APIs with retries and validation loops

- Hands-on LLM, RAG, ChromaDB or similar vector DB experience
- Production API reliability, CI/CD, Docker
- Strong TypeScript or Python
- Observability, evals, and incident response mindset
- Bonus: Cursor / Copilot / AI-assisted development workflows
