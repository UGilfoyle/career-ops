# Mode: gcc — Global Capability Center Targeting

Use when the user targets GCC/captive roles, asks about GCC strategy, or evaluates offers at Fortune 500 in-house India centers.

## GCC vs IT Services framing

| Dimension | IT Services | GCC / Captive |
|-----------|-------------|---------------|
| Employer | Client project delivery | Parent company payroll |
| Work type | Billable resource on client projects | Platform/product ownership |
| Tenure signal | Short project cycles | Long-term codebase ownership |
| Interview language | Delivery, SLAs, client satisfaction | Platform outcomes, global OKRs, reliability |
| Resume bullets | Multi-project delivery | Problem → Action → Result with business impact |

## GCC Signal Engine (score 0–5)

When evaluating a company or JD, score each signal. **3+ = high-value GCC target.**

| # | Signal | Look for |
|---|--------|----------|
| 1 | Expansion fuel | India GCC launch, funding, hiring news, new campus |
| 2 | Hiring velocity | 30+ open roles, repeat hiring in core teams, multi-city |
| 3 | Scope language | platform, global OKRs, reliability, telemetry, product ownership |
| 4 | Leadership signals | New VP/CXO hires from tier-1 firms |
| 5 | Future domains | fintech, UPI, EV, climate, cyber, compliance, data platforms |

Add to evaluation report as **Block H — GCC Signal Score** when company type is GCC or user is in GCC campaign mode.

## PAR resume bullets (GCC targets)

Rewrite experience bullets as **Problem → Action → Result**:

- **Weak:** "Worked on backend services"
- **Strong:** "Payment failures caused revenue leakage. I redesigned retry logic and monitoring. Failure rate dropped 42%."

Rules:
- Use **I**, not **we**
- Lead with the problem, then action, then quantified result
- Reframe IT services experience as platform reliability, cost reduction, automation impact, data quality

## 30-day GCC break-in system

Daily 30-minute block:

1. **10 targeted connections** — alumni at GCC, HR, hiring manager for target company
2. **3–5 curated applications** — email or value DM, avoid blind "Apply Now"
3. **1 mock interview / week** — platform-owner answers, STAR with Reflection
4. **Weekend power hour** — batch outreach, pitch deck, follow-ups

Track in dashboard **GCC Campaign** tab: company, DM sent, email sent, connection, story used, interview, follow-up.

## Red flags (GCC-specific)

- Buzzword-only JD with no platform ownership language
- No public hiring velocity but claims "GCC"
- Chaotic Glassdoor patterns (note, don't lead with negativity in interviews)
- Candidate unprepared: no PAR stories, no "why this company"

## Integration with other modes

- **oferta / auto-pipeline:** Add Block H when `classifyCompany(company) === 'GCC'`
- **pdf:** Use PAR bullet format + platform-owner summary
- **contacto:** Use value DM / email templates above
- **interview-prep:** Emphasize platform thinking, ownership, cross-functional impact
